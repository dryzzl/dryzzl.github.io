# Evan Ruiz — Engineering Portfolio

A responsive software engineering portfolio featuring interactive case studies for Task Manager REST API, Real-Time Fall Detection, Home Lab Monitoring Dashboard, and MapleStory Discord Bot, plus capstone and lab highlights.

## GitHub Pages

Repository: `dryzzl/dryzzl.github.io` · Website: https://dryzzl.github.io/

Publish the contents of this folder at the repository root on the `main` branch. In Settings → Pages, select Deploy from a branch, choose `main` and `/ (root)`, then save. GitHub Pages will provide the live URL after deployment.

No package installation or build step is required. `.nojekyll` tells GitHub Pages to serve the static files directly.

## Editing

- `style.css`: visual design and responsive layout
